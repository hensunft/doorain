# Использованные skills

Названия skill'ов не считались доказательством их возможностей: перед применением читались `SKILL.md`. Ниже — только то, что реально выполнялось.

| Skill | Как применён | Результат |
|---|---|---|
| **ponytail** (4.10.0, режим `full`, включён хуком сессии) | Лестница решений на протяжении всей разработки: без универсального agent-фреймворка, одна зависимость на задачу, стандартная библиотека/платформа раньше пакетов (нативный `<dialog>` вместо Radix, RRF в 5 строк, `html.parser` для HTML). Не runtime-зависимость приложения. | Каждая нетривиальная логика имеет проверку (`backend/tests`). Известные потолки описаны в `docs/decisions.md`. |
| **ponytail-review** | Запущен после реализации всех значимых модулей на всём коммите. | Найдено и применено: неиспользуемое поле конфигурации и свойство, неиспользуемый класс схемы, мусорные строки в `WorkspacePage`/тестах/`evals`, проп `onEvent`, локальные `import os`, обёртка над `shutil.which`; log retention вместо мёртвой настройки реализован через `logging: json-file` в compose. **net −45 строк**, после чего ruff/mypy/тесты повторно зелёные. Не заменяет ревью корректности и безопасности. |
| **minimalist-ui** | Прочитан. Взяты: тёплый монохром, белый/off-white фон, тонкие границы, отсутствие градиентов и тяжёлых теней, редакторский serif для заголовков, приглушённые подложки риска, контурные иллюстрации с одним пастельным пятном. | Явные исключения ТЗ: Inter и Lucide оставлены; bento-сетки, scroll-reveal и ambient-фоны не применялись (`docs/design-system.md`). |
| **impeccable** (4.3.1) | Прочитаны `SKILL.md`, `reference/operate.md`, `reference/craft-floor.md`; режим **Operate**. Применены: один шрифт-семейство UI, фиксированная шкала, skeleton-состояния, все состояния компонентов, видимый focus, цвет не единственный носитель смысла, контраст пар посчитан (≥ 4.5:1), отказ от eyebrow-меток/цветных borders/вложенных карточек, проверка в одном пакетном раунде скриншотов (1440/1024/768/390/zoom 200%). | Выявлено и исправлено визуальной проверкой: базовые CSS вне `@layer` перебивали классы (нечитаемый текст на тёмных кнопках), сжатая шапка на 390 px, мелкие подписи графа. **Лаунчер `impeccable context` и файлы PRODUCT.md/DESIGN.md не запускались/не создавались** (дизайн-контракт — `docs/design-system.md`). |
| **playwright-cli** | `SKILL.md` прочитан; e2e-сценарии написаны на `@playwright/test` (devDependency проекта, запускается командой `pnpm e2e`), а не через CLI-сессию skill'а. | 9 сценариев e2e, скриншоты 4 ширин и страниц в `docs/qa/`. |
| **Security-skills (Strix: `api-security-testing`, `find-security-vulnerabilities-in-code`, …)** | **Не запускались**: им требуются Docker-образ Strix и внешний LLM, то есть передача кода/запросов наружу; без отдельного решения владельца это недопустимо. | Выполнены локальные проверки: тесты безопасности (`test_security.py`, 21 тест), `ruff` с правилами `S`, `pip-audit` (без известных уязвимостей на 126 закреплённых пакетах основной группы), `pnpm audit --prod` (без известных уязвимостей), проверка изоляции сети в Docker. Полноценный автоматизированный пентест — остаётся задачей. |
