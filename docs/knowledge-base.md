# База знаний: импорт, редакции, индексация

Приложение **не скачивает законы** во время диалога. Обновление корпуса — управляемый импорт локальных проверенных файлов.

## Где брать материалы

Официальный портал правовой информации (publication.pravo.gov.ru / pravo.gov.ru) и справочно-правовые источники с законным основанием использования. Перечень кандидатов — `backend/corpus_manifest.json` (интерфейс: «База знаний → Перечень источников»). Это **кандидаты из концепции**, а не утверждение об актуальности или достаточности актов: реквизиты, редакции и действие проверяются при импорте.

Стартовый набор: 149-ФЗ, 152-ФЗ, 187-ФЗ, ст. 13.11 КоАП РФ. Расширенный: 98-ФЗ, 572-ФЗ, ст. 274.1 и гл. 28 УК РФ, Указ Президента №490, 123-ФЗ, 258-ФЗ, Кодекс этики ИИ (мягкое право), 63-ФЗ, часть IV ГК РФ, 236-ФЗ, 38-ФЗ, 126-ФЗ, 259-ФЗ. Статусы: `missing → imported → indexed → verified`.

> Учебники и базы третьих лиц охраняются авторским правом. Без лицензии или открытого основания их включать нельзя; форма импорта требует **основание правомерного включения** и **издание** (для цитаты нужны издание и страница).

## Процесс импорта

1. **Загрузка** (TXT, Markdown, HTML, PDF с текстовым слоем, DOCX): лимиты размера/типа, безопасное имя, SHA-256. Скан без текстового слоя отклоняется с инструкцией подготовить текст (OCR в MVP нет).
2. **Разбор в worker** → предпросмотр: автоопределённые реквизиты (номер, дата, редакция) — подсказка, а не истина; извлечённый текст показывается экранированным.
3. **Подтверждение метаданных** владельцем: тип источника (НПА/учебник/мягкое право), название, номер и дата акта, **дата редакции, действует с/по, дата проверки**, реквизит источника (URL не загружается), лицензия, темы.
4. **Неизменяемая редакция**: оригинал и нормализованный текст сохраняются; повторная загрузка того же файла идемпотентна; та же дата редакции с другим содержимым — отказ (`revision_exists`); правится только отметка проверки и дата утраты силы (с аудитом).
5. **Чанкинг**: НПА — статья → часть → пункт (длинное делится по границам предложений, overlap только там); учебник — по разделам с номером страницы. Один чанк — один акт и одна редакция. Стартовые размеры 500–900 токенов подлежат подбору на реальном корпусе.
6. **Generation**: embeddings (dense+sparse), контрольный поиск (каждая выбранная редакция находит собственный фрагмент), атомарная активация.

Дата загрузки, дата редакции, вступление в силу и дата проверки — **разные поля**. Поиск использует редакции, действующие на `as_of_date` сессии; неподтверждённая актуальность помечается в ответе.

## Сравнение редакций и цитаты

Сравниваются только реально загруженные редакции одного документа (текстовый diff по статьям/частям); отсутствующая редакция не генерируется. Цитата выгружается с реквизитами и происхождением (контрольная сумма файла корпуса).

## Демонстрационные данные

`fixtures/demo/*.txt` — вымышленные акты («ДЕМО-1-ФЗ» и др.). Они помечены `is_demo` и везде отображаются как «Демонстрационные данные — не нормативная база». Загрузка: `python -m app.cli load-demo-corpus` (для проверок стенда, не для реальных выводов).
