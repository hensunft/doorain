# Плотность интерфейса: что видно всегда, а что — по требованию

Правило: постоянное место занимает только то, что есть в первом списке экрана. Остальное появляется по наведению или клику, либо вынесено в настройки. Скрытое **не рендерится** (поповеры и меню монтируются только открытыми), а не прячется через `display: none`.

Сетка плотности: шаг 4 px; внутренние отступы карточек 16; между группами 24; между зонами рабочего пространства 32. Вложенных рамок нет: зона — поверхность без обводки, внутри неё рамку имеют только карточки. Всплывающее меню — единственная рамка поверх содержимого.

## Рабочее пространство (`/s/:id`)

| Видно всегда | По наведению или клику | В настройках |
|---|---|---|
| Название сессии, роль, дата правового среза | Переименование — клик по названию | Номер generation корпуса — «Режим разработчика» |
| Маркеры «Тестовый режим», «Модель недоступна», «Демонстрационные данные» (только когда они актуальны) | Условные обозначения карты и хронологии — кнопка «?» | Название и версия модели, пороги поиска, состояние сервисов, тема оформления — «О программе» |
| Переключатель «Карта тем / Хронология / План-схема» (на узком экране — только на вкладке «Портрет»), «Сменить роль», «Выгрузить PDF» | Фильтры карты, поиск по карте, экспорт SVG/PNG, «Разложить заново» — меню «Фильтры» | |
| Диалог и поле вопроса на всю ширину зоны; первичная кнопка экрана — «Отправить» под полем | Карточка узла — наведение на узел; «Ветка рассуждений» — клик по вопросу | |
| Карта (или хронология / план), мини-карта | Подсветка связанных рисков, ячеек и узлов (приглушение остальных до 25 %) — наведение на риск, ячейку или узел | |
| Риски: переключатели «Риски / Уточнения» и «Список / Матрица», сводка уровней, карточки | Статус, «Неприменимо ко мне», рекомендация — раскрытие карточки; P и S, основания, история — при выборе карточки | |
| Одна строка «Оценка носит информационный характер…» под списком рисков | Выгрузка CSV/Markdown — меню «↓»; свой риск — «+»; закрытые риски — «Показывать закрытые»; риски ячейки матрицы — клик по ячейке | |
| | Счётчик символов — только после 3 500 знаков; подсказка «Enter — отправить» — всплывающая подсказка поля ввода | |

## Кнопки

Одна система (`components/ui.tsx` → `Button`, классы `.btn*` в `styles/index.css`, витрина — `/styleguide`): первичная, вторичная, третичная, иконочная, опасная (заливка — только в подтверждении). На экране ровно одна первичная кнопка. Видимая высота 36 px (первичная на ключевых экранах — 44), зона нажатия ≥ 44 × 44. Состояния: покой, наведение (120 мс), нажатие (сдвиг на 1 px), фокус (золотое кольцо 3 px), заблокирована (45 %), загрузка (индикатор слева, ширина не меняется). Проверяется e2e-тестом «минимализм…».
