# Какие НПА нужны базе знаний DoorAIn

Дата составления: 24.09.2026. Документ — **перечень для администратора**, а не импорт: НПА в модель не «вшиты», знания поступают только из контролируемого корпуса. Приложение ничего не скачивает и не индексирует само; акты загружает администратор (`python -m app.cli kb add <файл|url> --license public_domain_official …` или раздел «База знаний»), после чего выполняется переиндексация.

Перечень — **покрытие тем, заявленных в продукте** (`knowledge_base/manifest.yaml`, `backend/app/services/risks/methodology.py`), а не список законов, обязательных для каждого пользователя. Применимость к конкретной ситуации определяет ответ по загруженным нормам.

Как читать статус:
* **загружено** — в рабочей базе есть проверенная редакция;
* **требуется обновление** — загруженная редакция старше действующей;
* **не загружено** — по теме сервис отвечает отказом и называет непокрытую тему.

Живой статус по манифесту — в интерфейсе («База знаний» → «Перечень источников из концепции») и командой `python -m app.cli kb doctor`. Ниже — состояние рабочей базы стенда на 24.09.2026, после вывода тестовых актов.

**Сверка реквизитов.** Номера и названия ниже сверены с манифестом и официальной публикацией там, где это указано. Действующие редакции **не** сверялись построчно с pravo.gov.ru: при загрузке каждого акта администратор фиксирует дату редакции (`revision_date`) и дату проверки (`verified_at`). Устаревшая редакция не должна выдаваться за действующую: без `verified_at` сервис помечает ответ «актуальность не подтверждена».

## 3. Непокрытые темы

При текущем состоянии рабочей базы (загружен только 152-ФЗ) не покрыты темы «Информация и защита информации», «КИИ», «ИИ», «Электронная подпись», «Интеллектуальная собственность в IT», «Интернет-бизнес и реклама», «Цифровые активы», «Ответственность». По ним сервис отвечает отказом и прямо называет непокрытую тему и нужные акты из манифеста. Это делает `backend/app/services/ingestion/kb.py::coverage_gaps`, текст отказа формирует `pipeline._refuse`. Отсутствие НПА не подменяется демонстрационным текстом.

Без норм об ответственности (п. 4, 11) риски создаются только с тяжестью S ≤ 2 либо остаются «не оценён». Так работает методика, а не ошибка.
