# Дизайн-система

Спокойное рабочее пространство в духе Notion: **документный интерфейс**, а не лендинг. Режим impeccable — *Operate* (человек выполняет задачу): сканируемость и консистентность важнее выразительности; бренд живёт в деталях.

## Токены (`frontend/src/styles/index.css`)

| Токен | Значение | Использование |
|---|---|---|
| canvas | `#FFFFFF` | основной фон |
| sidebar | `#F7F7F5` | боковая панель, «второй нейтральный слой» |
| ink | `#37352F` | текст (контраст 12.3:1 на белом) |
| muted | `#6B6B66` | вторичный текст (5.4:1 на белом, 5.0:1 на sidebar) |
| line | `#E9E9E7` | разделители, тонкие границы (1 px) |
| graphite | `#2F2E2B` | кнопки, активное состояние (белый на нём 13.6:1) |
| brand | `#7A3447` | только бренд/выделение узла (8.7:1) |

**Риск — единственное многоцветное исключение**, цвет всегда дублируется текстом, значком и числом:

| Уровень | Цвет текста | Мягкая подложка | Контраст пары |
|---|---|---|---|
| Низкий | `#3F6B55` | `#EAF3EE` | 5.38:1 |
| Средний | `#8A641F` | `#FAF3E0` | 4.83:1 |
| Высокий | `#B4473E` | `#FBEDEB` | 4.71:1 |
| Критический | `#70263A` | `#F5E8EC` | 8.70:1 |
| Нет рисков / мало данных | `#6B6B66` на sidebar | — | нейтральный серый, **не** «безопасно» |

Значки уровней различаются по силуэту (круг, треугольник, восьмиугольник, щит). Пары посчитаны по WCAG (скрипт в истории проверки); на белом все риск-цвета ≥ 5.35:1.

## Типографика и форма

* Приложение: **Inter** (SIL OFL; файлы кириллицы и латиницы — `public/fonts`, лицензия рядом), запасной стек `Segoe UI, Arial`. Внешних шрифтов и CDN нет. Заголовки/отчёт: `Georgia`, в PDF — DejaVu Serif.
* Основной текст 15 px, длинные ответы — line-height ≈ 1.65, ширина ≤ 72ch. Шкала фиксированная (13/15/16/20/26), без fluid-типографики.
* Радиусы 4–8 px, границы 1 px, теней практически нет; анимации 120–180 мс только для обратной связи; `prefers-reduced-motion` отключает анимации.
* Иллюстрации (`components/art.tsx`): контурные SVG в стиле рисунка тушью — дверь, портретная рамка, карта связей с одним смещённым пастельным пятном. Пиктограммы — единый набор Lucide, без emoji.

## Компоновка

| Ширина | Вид |
|---|---|
| ≥ 1280 | три изменяемые панели: **чат 38 / портрет 34 / риски 28** (мин. 320/300/260 px, разделители доступны с клавиатуры) |
| 768–1279 | чат + переключаемая правая панель «Портрет / Риски» |
| < 768 | вкладки «Диалог / Портрет / Риски»; все панели остаются смонтированными: ввод, прокрутка и выделение сохраняются |

Таблица рисков разворачивается на всю ширину (полноэкранный диалог) с карточкой подробностей; источник открывается в drawer справа без потери контекста.

Состояния: `loading` (skeleton), `empty` (объясняет действие), `error` (с повтором), `partial`/`cancelled` (пометки в ответе), `model unavailable`, `corpus empty`, `analysis pending/failed` (повтор без дублей), `offline` (баннер, ввод сохраняется).

## Доступность

Видимый focus (2 px графит), нативный `<dialog>` (focus trap, Escape, возврат фокуса), labels у всех полей, `role="log" aria-live="polite"` у диалога, `aria-sort`/`aria-pressed`/`aria-selected` у таблицы, вкладок и переключателей. У графа есть **текстовые эквиваленты**: «Список» (дерево тем → вопросов → норм/рисков) и «Хронология». Enter — отправить, Shift+Enter — перенос, «Стоп» во время генерации; чтение истории вверх не прерывается автопрокруткой («Новые сообщения ↓»).

## Что не применялось

Из `minimalist-ui` не взяты запреты на Inter и Lucide (явное исключение ТЗ), bento-сетки, scroll-reveal и ambient-фоны: для рабочего инструмента с таблицами и графом они не подходят.
