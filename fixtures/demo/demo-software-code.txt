Статья 2. Права на программу, созданную обучающимся
1. Исключительное право на программу для ЭВМ, созданную обучающимся в рамках учебного проекта, принадлежит обучающемуся-автору, если договором с образовательной организацией не предусмотрено иное.
2. Код, написанный студентами в проектах, используется организацией только на основании договора, который определяет объём передаваемых прав.
